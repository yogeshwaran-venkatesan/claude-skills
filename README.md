# claude-skills

Personal Claude skills by Yogesh.

| Skill | Purpose |
|---|---|
| [client-web-design](client-web-design/SKILL.md) | Custom, non-generic client website design with a design spec, hard bans on AI clichés, Playwright checks and a pre-handover checklist. |

## Use in Claude Code (VS Code)

```bash
git clone https://github.com/yogeshwaran-venkatesan/claude-skills.git %USERPROFILE%\.claude\skills
```

Run `git pull` in that folder to get updates, then restart Claude Code.
