# claude-skills

Personal Claude skills by Yogesh.

| Skill | Purpose |
|---|---|
| [frontend-design](frontend-design/SKILL.md) | Anthropic's official skill for distinctive visual design: aesthetic direction, typography, avoiding templated defaults. Apache 2.0, see its LICENSE.txt. |
| [client-web-design](client-web-design/SKILL.md) | Custom, non-generic client website design with a design spec, hard bans on AI clichés, Playwright checks and a pre-handover checklist. |
| [web-design-guidelines](web-design-guidelines/SKILL.md) | Vercel. Audits UI code against Vercel's Web Interface Guidelines (fetched live each run): accessibility, focus states, forms, responsive. MIT. |
| [vercel-composition-patterns](vercel-composition-patterns/SKILL.md) | Vercel. React component architecture: compound components, no boolean-prop sprawl. React-only. MIT. |
| [webapp-testing](webapp-testing/SKILL.md) | Anthropic. Playwright testing of local web apps: screenshots, console logs, UI checks. Apache 2.0. |

## Use in Claude Code (VS Code)

```bash
git clone https://github.com/yogeshwaran-venkatesan/claude-skills.git %USERPROFILE%\.claude\skills
```

Run `git pull` in that folder to get updates, then restart Claude Code.
